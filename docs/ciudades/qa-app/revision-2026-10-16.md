# Revisión del modo Ciudades · 16 de octubre de 2026

Revisión del código posterior a `10d6011`, sin publicar contenido, ejecutar escrituras en Supabase ni generar una build.

## Comprobado

- Catálogo remoto con acceso anónimo: 235 nombres bilingües y 235 dioramas jugables. Las 235 URLs responden con WebP accesible y los nombres y encuadres coinciden con los datos locales.
- Rondas por continente y dificultad: cuatro opciones distintas, un acierto y preguntas sin repetir. Las rondas se acortan si el filtro contiene menos de diez ciudades.
- Distribución: Europa 94, América 53, África 23, Asia 53 y Oceanía 12.
- `npm run test:cities`: 17 pruebas superadas. `npm run typecheck`: correcto. `node scripts/check-i18n.mjs`: paridad de 1247 claves ES/EN; conserva nueve avisos de literales ya existentes. `git diff --check`: correcto.
- La cola de imágenes, la reutilización de referencias decodificadas, los límites de caché y el encuadre común cuentan con pruebas. Esta revisión no sustituye una prueba nativa de la build instalada.

## Corrección aplicada

Si se pulsaba «Jugar otra vez» y fallaba la descarga de las primeras ciudades, `CitiesGame` guardaba el error, pero el resultado no lo mostraba. Ahora aparece el aviso y el botón pasa a «Reintentar», reutilizando exactamente la ronda cuya preparación falló. La salida al selector sigue disponible durante la carga y cancela el intento pendiente.

Es una corrección de código: no cambia una build de TestFlight que ya esté subida. Se incluirá cuando se distribuya una nueva build o una actualización compatible por el flujo habitual del proyecto.
