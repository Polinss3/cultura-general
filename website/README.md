# Web oficial de CG Trivia

Sitio estático bilingüe de `cg-trivia.pablobrasero.com`. Incluye portada,
soporte, privacidad, términos, aviso legal, cookies, accesibilidad, opciones de
privacidad, eliminación de datos, `app-ads.txt`, `robots.txt`, `sitemap.xml` y
`security.txt`.

```sh
npm run build
npm test
```

El resultado publicable queda en `dist/`. Los datos legales deben mantenerse
sincronizados con el comportamiento de la app y con las fichas de App Store y
Google Play.
